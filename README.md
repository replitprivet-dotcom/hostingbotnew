# Simran Hosting Bot v3.5 (Jarvis Autonomous AI Edition)

Complete Python Telegram Hosting Bot with Autonomous Self-Healing AI & Cloud Storage.

## ✨ Features
- **Container / Non-Root Compatible**: Safe isolated sandbox execution without permission errors.
- **JARVIS AI Self-Healing**: Automatically catches runtime exceptions, missing packages, auto-installs via pip, patches syntax/logic bugs using DeepSeek-V3, and reboots.
- **6-Tier Hosting Plans**: Free, Starter, Basic, Pro, Enterprise, Lifetime.
- **Automated Payment Verification**: Google Pay, PhonePe, Paytm, and Bank transfer.
- **MongoDB Sync & Cloud Backup**: Auto-sync and `/gdrive <bot_id>` single-zip cloud backup.
- **24/7 Webhook / Keep-Alive**: Built-in Flask daemon.

## 🚀 Getting Started
```bash
pip install -r requirements.txt
python3 main.py
```
